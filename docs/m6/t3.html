Electromagnetic Induction: Flux, Faraday and Lenz

电磁感应：磁通量、法拉第电磁感应定律和楞次定律 · 零基础讲解

这一章讲怎样用磁场“变”出电。最核心的一句话：穿过线圈的 flux（磁通量）一变，就产生 emf（电动势）。学会三件事：flux 有多少、emf 有多大、电流朝哪走。后面的运动导线、磁铁和两个线圈，就都是同一个规则。

Magnetic flux

有多少磁感线穿过线圈。角度 θ 从 normal（法线）量，不从线圈平面量。

热身

先会这 4 样Before we start

  1. 磁感线和 B：磁感线从 N 极出来，进 S 极。线越密，磁场越强。B 的单位是 T（tesla，特斯拉）。
  2. Right-hand grip rule（右手螺旋定则，也叫安培定则）：右手握住线圈，四指顺着电流弯，大拇指指的就是线圈里面的磁场方向。
  3. Right-hand palm rule（右手掌定则）：右手伸平，四指 = 磁场 B，大拇指 = 正电荷的速度 v（或电流 I），手掌推的方向 = 力 F。
  4. 三个 cos 值：cos 0° = 1，cos 90° = 0，cos 180° = −1。
3.1

磁通量：穿过线圈的磁场有多少Magnetic flux

一句话Magnetic flux 告诉你有多少磁场穿过一个线圈。它看三样东西：磁场多强、面积多大、角度多少。

  • Magnetic flux（磁通量，Φ）：穿过一个面的磁场有多少。可以想成“穿过线圈的磁感线有几条”。单位是 weber（韦伯，Wb）。
  • Plane（线圈平面）：线圈里面那个平面，像鼓皮。
  • Normal：一支想象出来的箭头，和线圈平面成 90°。
  • θ 是 B 和 normal 的夹角，不是和 plane 的夹角。题目给的是“和 plane 的夹角”，就用 θ = 90° − 那个角。
  • 只有沿着 normal 的那部分磁场能穿过去：B∥ = B cos θ。
  • 类比：用水桶接雨。桶口朝上，接到的雨最多；桶斜着，接得少；桶口侧过来，一滴也接不到。
θ = 0°

plane ⊥ B。磁感线全部穿过。Φ = BA，最大。

斜着

只有一部分穿过。Φ = BA cos θ。

θ = 90°

plane ∥ B。磁感线顺着线圈擦过去，一条也不穿过。Φ = 0。

  • 1 Wb = 1 T m²。B 垂直于 plane 时，B = Φ/A，就是每平方米的 flux。所以 B 也叫 magnetic flux density（磁通密度，即磁感应强度）。
  • 把磁场反过来（或者把线圈翻个面）：flux 从 +BA 变成 −BA。所以 |ΔΦ| = 2BA，不是 0。

改变 flux 的三种方法

改什么怎么改
改 B把磁铁移近或拿远；改变电磁铁里的电流；把磁场打开、关掉或反过来。

注意：线圈在一个很大的匀强磁场里面滑来滑去，穿过它的 flux 一直一样，所以没有 emf。

3.2

只有变化才产生 emfFaraday's law

一句话只有变化的 flux 才产生 emf。flux 不变，就什么都没有，不管它有多大。

  • Electromagnetic induction（电磁感应）：靠改变 flux 来产生 emf。“产生”这个词，英文叫 induce（感应）。
  • emf（ε，electromotive force）：名字里有 force，但它不是力。它是每库仑电荷得到的能量。单位是 volt（V）。
  • 磁铁动得更快、磁铁更强、线圈圈数更多，emf 都更大。
  • Faraday's law（法拉第电磁感应定律）：感应 emf 和 flux 的变化率（rate of change）成正比。
  • 线圈有 N 圈，每圈的 emf 加在一起，就像几节电池串在一起。
  • 闭合电路（closed circuit）：有 induced current（感应电流）在流，I = ε/R。断路（open circuit）：有 emf，但没有电流。
  • 类比：flux 像银行卡里的余额，emf 像每天进出的钱。余额再多，一分不动，进出就是 0。

从 Φ–t 图读出 emf

  • |ε| = N × gradient。Gradient（斜率）就是图线有多陡。
  • 图线陡：emf 大。图线平：emf = 0。
  • 图线上升的一段和下降的一段，emf 的符号相反。
  • 在 3.5 的 动画 4 里，Φ–t 图和 ε–t 图上下对齐，可以直接看到这一点。

3.3

感应电流朝哪走？Lenz's law: the direction of the current

一句话感应电流总是和“产生它的变化”对着干。Lenz's law（楞次定律，原话要背）：感应电流的方向，使它产生的磁场反对产生它的 flux 变化。

考试要用英文写出这一句（booklet 原话，要背）：
“The induced current flows in the direction that makes a magnetic field opposing the change in flux that produced it.”
关键词：induced current、magnetic field、opposing the change in flux。

  • Lenz's law 就是 Faraday 公式里的那个负号。它来自能量守恒（这一节最后讲）。
  • 断路时没有电流。这时 emf 的方向，就是它“想”推动的那个电流的方向。
  • 感应电流自己也会产生磁场，下面叫它 induced B（感应磁场）。
  • 它反对的是变化，不是磁场本身。类比：一个很怕变化的人。你往里塞，他往外推；你往外拿，他往回拉。
flux 增加

induced B 和原来的 B 反向，想把 flux 压回去。

flux 减少

induced B 和原来的 B 同向，想把 flux 补回来。

  • Right-hand grip rule：四指顺着电流弯，大拇指 = 线圈里面的磁场。反过来也能用：你看过去电流是逆时针，这一面就是 N 面；是顺时针，就是 S 面。

判断电流方向的三步

  1. 原来的 B 朝哪？flux 在变大还是变小？
  2. 用 Lenz's law 找出 induced B 朝哪。
  3. 用 grip rule，从 induced B 找出电流方向。

注意：说“顺时针”或“逆时针”时，一定要说从哪边看（比如“从磁铁那边看”）。不说从哪边看，这个答案没有意义。

更快的方法：pole method

  • Pole method（磁极法）：磁极靠近时，线圈近端变成同名极，把它推开。磁极离开时，近端变成异名极，把它拉住。
  • 不管哪种情况，线圈都在反对磁铁的运动。
N 极靠近

近端变成 N，推开磁铁。induced B 指向磁铁。从磁铁那边看：逆时针。

N 极离开

近端变成 S，拉住磁铁。induced B 背向磁铁。从磁铁那边看：顺时针。

Lenz's law 和能量守恒

  • 假设线圈吸引靠近的磁铁：磁铁会越跑越快，能量凭空多出来。这违反 law of conservation of energy（能量守恒定律）：能量不能被创造，也不能被消灭。
  • 所以线圈一定会推回去。你克服这个推力做的功 → 电能 → 热。
  • 断路：没有电流，所以也不推回去。
3.4

运动的导线也会产生 emfMotional emf: a straight wire moving in a field

一句话一根金属棒横着切过磁场，它的两端之间就有 emf。

一根棒自己动

  • 用 palm rule：四指 = B，大拇指 = 正电荷的 v，手掌推的方向 = 力。
  • 棒向右动，B 进纸（×）：正电荷被推向上。Free electrons（自由电子，能在金属里移动的电子）被推向下。
  • 结果上端变成 +，下端变成 −，就像一节电池。这叫 motional emf（动生电动势）。
  • 电荷越堆越多，会产生一个电场往回推。电场力和磁场力一样大时，电荷就不再堆了。

放在导轨上

  • 把棒放在两条导轨上，导轨左端接一个电阻 R，就成了闭合电路（像动画 3）。棒向右走、离开 R：电流沿着棒向上流，整圈是逆时针（从纸前面看）。
  • 棒里有电流，又在磁场里，所以受力 F = lIB。这个力反对运动（Lenz）。
  • 所以要一直推，棒才能匀速走。推力做的功，最后变成 R 里的热。
  • Faraday 的看法：棒往前走，扫过一块面积，回路里的 flux 变大，所以有 emf。两种看法，答案一样。
  • 棒顺着磁感线走，或者沿着自己的长度方向滑：它没有切过磁感线，ε = 0。
Induction（这一章）

运动 → 电流。导线在磁场里动，产生电流。

Motor effect

电流 → 运动。Motor effect（磁场对电流的作用，也叫安培力）：有电流的导线在磁场里被推。

也可以自己推导：时间 Δt 里，棒扫过的面积 ΔA = lvΔt，所以 ΔΦ = BlvΔt。用 Faraday's law，N = 1：|ε| = ΔΦ/Δt = lvB。
陷阱：l 是在磁场里面的长度，不是整根导线的长度。

3.5

磁铁穿过线圈、金属板里的涡流A magnet moving through a solenoid · Metal plates: eddy currents

一句话不管是什么原因，只要 flux 变了，就有 emf。螺线管里的磁铁、金属板、两个靠近的线圈，都按同样的规则来。

Solenoid（螺线管）：一个很长、绕了很多圈的线圈。

磁铁穿过螺线管

  1. 靠近：flux 增加，emf 朝一个方向。这是第 1 个 pulse（脉冲）。
  2. 在中心：flux 最大，但这一瞬间不变，所以 ε = 0。
  3. 离开：flux 减少，emf 反过来。这是第 2 个 pulse。
  • 磁铁越快，pulse 越高、越窄。
  • 掉下来的磁铁，离开时比进来时快。所以 pulse 2 更高、更窄。
  • 两个 pulse 的面积一样，都是 N|ΔΦ|。快了，就高了，但时间也短了。
  • 闭合电路：线圈推开上面的磁铁，又拉住下面的磁铁。两个力都向上，都反对下落。一部分重力势能（gravitational potential energy）变成热，磁铁掉得更慢。

金属板：涡流

  • Eddy currents（涡流）：在整块金属里面绕圈的感应电流。只在 flux 变化的地方才有。方向用 Lenz's law 判断。
  • 下面是一块金属板向右穿过磁场，磁场进纸（×），从纸前面看：
正在进入磁场的那一块

flux 增加 → 逆时针的涡流。

正在离开磁场的那一块

flux 减少 → 顺时针的涡流。

完全在磁场里面的那一块

flux 不变 → 没有涡流。

  • 每个涡流圈受的力，都反对运动。板慢下来，动能变成热。这叫 magnetic braking（电磁制动，也叫电磁阻尼）。
  • 用途：刹车、induction cooktops（电磁炉）、metal detectors（金属探测器）。
  • 坏处：transformer（变压器）的铁芯里也有涡流，会浪费能量（下一章讲）。
  • 磁铁掉进铜管、被涡流刹慢，可以看 Topic 5 的动画 5。
3.5

两个线圈：互感One solenoid near another

一句话一个线圈里的电流一变，旁边的线圈里就有 emf。电流不变，就没有。

  • Mutual induction（互感）：primary coil（原线圈，也叫初级线圈，接电源）里的电流一变，旁边的 secondary coil（副线圈，也叫次级线圈）里就感应出 emf。
  • 带着稳定电流的线圈，如果把它移进、移出另一个线圈，作用就像一根条形磁铁。

开关一开一关

  1. 开关闭合：primary 的电流从 0 变大，secondary 里有短暂的 emf。secondary 的 induced B 反对那个正在变强的磁场。
  2. 一直闭合：电流不变，flux 不变，没有 emf。
  3. 开关断开：电流变小，又有一个短暂的 emf，方向反过来。
  • 类比：坐电梯。只有启动和停下的那一下你有感觉，匀速走的时候没感觉。
  • Soft iron core（铁芯，也叫软铁芯）很容易被磁化。它把更多 flux 引进 secondary，所以 emf 更大。
  • AC（交流电：电流的大小和方向一直在变）电源：电流一直在变，所以一直有 emf。这就是 transformer（下一章）。稳定的 DC（直流电）：只在开、关的那一刻有 emf。
  • secondary 的能量从哪来？来自电源。如果是移动线圈产生的，就来自你做的功。

绕在长螺线管上的线圈

  • 一个很长的空心 solenoid 当 primary，外面再绕一个线圈当 secondary。primary 的 flux 全部穿过 secondary。
  • secondary 每一圈的 flux：Φ = BA，其中 B = μ0NpIp/L。
  • 再用 Faraday's law，就得到下面的式子。Ip 变得越快，emf 越大。

3.6

两个要知道的实验Key experiments

Faraday 的电磁感应实验（1831）

目的
证明变化的 flux 会感应出 emf。
做法
① 把磁铁推进、拉出一个线圈，线圈接一个 galvanometer（灵敏电流计，测很小电流的表）。② 让一根导线横着穿过磁铁的磁场。③ 两个线圈绕在同一个铁环上，把开关闭合、再断开。
结果
只有在“有东西在变”的时候，指针才动一下。相反的变化，指针朝相反方向动。变得越快，指针动得越大。
结论
只有 flux 在变的时候，才有感应 emf。只有 relative motion（相对运动）才算数。
意义
和 Ørsted（奥斯特）1820 年的发现一起，把电和磁连在了一起。

涡流：下落的磁铁和摆动的金属板

目的
证明涡流反对产生它的运动。
做法
一块磁铁分别掉过 PVC 管、铜管和开缝的铜管。实心金属板和开缝的金属板在磁极之间摆动。
结果
下落时间：PVC 0.41 s（自由落体），开缝铜管 0.56 s，铜管 3.57 s。实心板很快停住，开缝的板一直摆。
结论
铜里的涡流反对下落（Lenz）。少掉的重力势能变成热。开缝切断了电流的圈，所以刹车变弱。
意义
Lenz's law 和能量守恒的证据。电磁刹车就是用这个原理。

考试前背这 5 句

  1. Φ = BA cos θ，θ 从 normal 量。B、A、θ 任何一个变，Φ 就变。
  2. 只有变化的 flux 才产生 emf：ε = −N ΔΦ/Δt。
  3. Lenz：感应电流反对 flux 的变化，因为能量守恒。
  4. 运动的棒：ε = lvB（不在 sheet 上）。
  5. 磁铁穿过线圈：两个方向相反的 pulse。两个线圈：只有 primary 电流在变的时候，才有 emf。

常见错误

错：θ 是 B 和线圈平面的夹角。
对：θ 是 B 和 normal 的夹角。plane ∥ B 时 θ = 90°，Φ = 0。
错：面积 200 cm² 直接代 200。
对：先换成 m²：200 × 10−4 = 0.02 m²。
错：磁场反过来，flux 大小一样，所以 ΔΦ = 0。
对：从 +BA 变到 −BA，|ΔΦ| = 2BA。
错：flux 很大，emf 就很大。
对：emf 看 flux 变得多快。flux 再大，不变就是 0。
错：induced B 总是和原来的 B 反向。
对：flux 增加时反向，flux 减少时同向。它反对的是变化。
错：答“电流是顺时针”就完了。
对：要说从哪边看，比如“从磁铁那边看是顺时针”。
错：ε = lvB 里的 l 用整根导线的长度。
对：l 是在磁场里面的那一段。
错：开关一直闭合，secondary 里一直有 emf。
对：DC 只在开、关的那一刻有 emf。一直有 emf 要用 AC。

检查

快问快答点一下看答案

1. 线圈平面和磁场平行。θ 是多少？Φ 是多少？

θ = 90°，Φ = 0。θ 是 B 和 normal 的夹角。plane ∥ B 时 normal ⊥ B，cos 90° = 0，没有磁感线穿过。

2. 线圈面积 200 cm²，B = 0.5 T，线圈平面和 B 成 30°。Φ 是多少？

Φ = 0.005 Wb（5 × 10−3 Wb）。先换单位：A = 200 × 10−4 = 0.02 m²。再换角度：θ = 90° − 30° = 60°。Φ = 0.5 × 0.02 × cos 60° = 0.005 Wb。

3. 一块很强的磁铁放在线圈里，一动不动。电流计有读数吗？

没有。flux 很大，但不变，ΔΦ = 0，所以 ε = 0。只有变化的 flux 才产生 emf。

4. 100 圈的线圈，面积 0.02 m²，正对 B = 0.5 T 的磁场。磁场在 0.1 s 里反过来。平均 emf 多少？电路电阻 4 Ω，电流多少？

ε = 20 V，I = 5 A。flux 从 +BA 变到 −BA：|ΔΦ| = 2BA = 2 × 0.5 × 0.02 = 0.02 Wb（不是 0）。|ε| = N|ΔΦ|/Δt = 100 × 0.02 / 0.1 = 20 V。I = ε/R = 20/4 = 5 A。

5. 条形磁铁的 S 极从线圈旁边离开。线圈近端变成什么极？推还是拉？

近端变成 N，拉住磁铁。Pole method：磁极离开，近端变成异名极，互相吸引，反对磁铁离开。

6. 导轨上的棒：l = 0.50 m，B = 0.80 T，v = 2.0 m s−1，R = 2.0 Ω。求 ε、I 和棒受的力。

ε = 0.80 V，I = 0.40 A，F = 0.16 N，方向和运动相反。ε = lvB = 0.50 × 2.0 × 0.80 = 0.80 V。I = ε/R = 0.80/2.0 = 0.40 A。F = lIB = 0.50 × 0.40 × 0.80 = 0.16 N。按 Lenz，这个力反对运动，所以要一直推。

7. 磁铁从上往下掉过一个线圈。为什么第二个 pulse 更高、更窄？两个 pulse 的面积呢？

离开时磁铁更快；面积一样。磁铁越掉越快，离开时比进来时快，flux 变得更快，所以 emf 更大，时间更短。两个 pulse 的面积都等于 N|ΔΦ|。

8. 长空心 solenoid：Np = 1000，L = 0.50 m，A = 4.0 × 10−4 m²，外面绕 Ns = 50 圈。Ip 在 0.010 s 里从 0 升到 2.0 A。εs 多少？之后 Ip 一直是 2.0 A 呢？

约 0.010 V；之后是 0。2.0 A 时 B = μ0NpIp/L = 4π × 10−7 × 1000 × 2.0 / 0.50 = 5.03 × 10−3 T。每圈 Φ = BA = 5.03 × 10−3 × 4.0 × 10−4 = 2.01 × 10−6 Wb。|εs| = NsΔΦ/Δt = 50 × 2.01 × 10−6 / 0.010 = 1.0 × 10−2 V。电流不变以后，flux 不变，emf = 0。
