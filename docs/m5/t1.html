Projectile Motion

抛体运动 · 零基础讲解

这一章讲扔出去的东西怎么飞。秘诀只有一个：把运动拆成水平和竖直两个方向，分开算，只共用时间 t。拆开以后，每个方向都是你学过的直线运动。

规则 ①
Independent motions

斜着的速度先拆成水平和竖直两部分。两部分互不影响，只共用时间 t。水平的 vx 不变；竖直的 vy 每秒变 9.8 m s−1。

ux = u cos θ　uy = u sin θ

只用于恒定加速度。每个方向各用一次。x 和 y 的数不能混着用。

规则 ③
Sign convention

Origin（原点）就是发射点。向上、向前为正。所以整个飞行里竖直加速度都是负的，最高点也一样。

ax = 0　ay = −g = −9.8 m s−2

热身

先会这 4 样Before we start

  1. Vector（矢量）有大小和方向，画成一个箭头。一个斜着的箭头，可以拆成一个水平箭头加一个竖直箭头。
  2. 直角三角形里：cos θ = 邻边 / 斜边，sin θ = 对边 / 斜边。计算器要用 degree mode（角度制）。
  3. Displacement（位移）s 和速度都带正负号，正负号就是方向。Speed（速率）只有大小，没有方向。
  4. Newton's second law（牛顿第二定律）Fnet = ma。Fnet 是 net force（合力）：所有力加起来的总和。没有合力，就没有加速度，速度就不变。Acceleration due to gravity（重力加速度）g = 9.8 m s−2，向下：速度每秒变 9.8 m s−1。
1.1

抛体：两个方向分开看The projectile model

一句话扔出去的球，同时在往前走和上下动。这两个运动互不影响。往前的速度一直不变；上下的速度每秒都被重力改变一样多。

  • Projectile（抛体）：被扔出去或发射出去、没有发动机推着的物体。
  • Component（分量（分力））：一个 vector（带方向的箭头量）指向某一个方向的那一部分。
  • 抛体的 model（模型，一个能拿来计算的简单描述）有两个 assumption（假设）：没有空气阻力；g = 9.8 m s−2 恒定，竖直向下。

为什么两个方向互不影响？

  • 重力只往下拉，水平方向没有力。没有水平力，就没有水平加速度（Newton's second law），所以 vx 不变。
  • 竖直方向只有重力，所以 vy 每秒变 9.8 m s−1。
  • 两个运动是 independent（相互独立）的：互不影响，只共用时间 t。
  • 类比：想象两个影子。地上的影子只管匀速往前走；墙上的影子只管上下动。两个影子用同一块秒表。
A：自由落下

从台边松手，直直往下掉。

B：同时水平抛出

同一高度、同一时刻往前扔。每 0.1 s 看一次，A 和 B 一样高，同时落地。

B 往前的速度不会让它掉得慢一点，也不会掉得快一点。动画 1 会演示这件事。

  • 往前走的距离跟 t 成正比；往下掉的距离跟 t² 有关。所以路径（trajectory，轨迹）是一条 parabola（抛物线）：以最高点左右对称的曲线。
  • 符号：origin 在发射点，向上、向前为正。所以 ay = −g = −9.8 m s−2，整个飞行都是，连最高点也是。

1.1

最简单的情况：水平抛出The simplest case: a horizontal launch

一句话水平抛出时 uy = 0，竖直方向就像从静止落下。所以在空中的时间只看高度。

  • 从桌子、台阶、悬崖边水平抛出：发射速度是水平的，所以 uy = 0。
  • 竖直方向就像从静止落下。往前扔得多快，都不影响掉下去要多久。
  • 在空中的时间只看高度。高度变 4 倍，时间变 2 倍（因为 √4 = 2）。速度不变时，射程也变 2 倍。

1.2

最大高度、飞行时间和射程Height, time of flight, range and final velocity

一句话到最高点时，竖直速度有一瞬间等于 0。抓住这一点，就能算出最大高度；在平地上，还能算出飞行时间和射程。

  • Maximum height（最大高度）hmax：比发射点高出的最大距离。
  • Time of flight（飞行时间）tflight：从发射到落地的时间。
  • Range（射程（水平射程））R：从发射点到落地点的水平距离。
最高点

只有 vy = 0。球还在以 vx 往前走，所以速度 = vx，不是 0。

加速度

每一点都是 g 向下，从来不是 0。最高点也一样。

  • 平地上，路径是 symmetrical（对称的）：下来的路像上去的路照镜子。上升时间 = 下降时间。

也可以自己推导：把 ay = −g 代进 sheet 上的公式。最高点 vy = 0：v = u + at 给出 0 = uy − gttop；v² = u² + 2as 给出 0 = uy² − 2ghmax。落地时 sy = 0：s = ut + ½at² 给出 0 = t(uy − ½gt)，所以 tflight = 2uy/g（t = 0 是发射那一刻）。再用 R = uxtflight = u cos θ × 2u sin θ / g = u² sin 2θ / g，因为 2 sin θ cos θ = sin 2θ。
陷阱：用 uy，不是 u。代 g = 9.8，不是 −9.8（负号已经在式子里了）。

  • 把 uy = u sin θ 代进去：hmax = u² sin²θ / 2g，tflight = 2u sin θ / g。
  • 同一个角度，u 变 2 倍：时间变 2 倍；高度和射程变 4 倍（因为式子里是 u²）。
1.2

射程和 45° 规则Range and the 45° rule

一句话射程要靠两样东西：水平速度和在空中的时间。平地上 45° 两样搭配得最好，所以射程最远。

  • 角度低：水平速度大，但很快就落地。角度高：在空中很久，但往前走得慢。
  • 45° 射程最远：2θ = 90° 时 sin 2θ = 1，最大。这时 Rmax = u²/g。
  • 这条只在平地、没有空气阻力时成立。
  • Complementary angles（互余角（余角））：加起来是 90° 的两个角，比如 30° 和 60°。它们的射程一样。陡的那个飞得更高，在空中更久。
  • 类比：用水管浇花。水管放平，水很快落地；对着天，水又落回脚边；斜着举，水才喷得远。
30°

低一点、快一点落地。射程和 60° 一样。

60°

更高，在空中更久，但往前走得慢。射程和 30° 一样。

射程还是用上面的 R = u² sin 2θ / g，这里没有新公式。动画 3 的抛出点高度 h 先放在 0，看看 30° 和 60°；下一节再把发射点抬高。

1.2

从高处抛出Launching from a height

一句话发射点比落地点高时，落地那一刻 sy = −h。解一个关于 t 的二次方程，取正的那个解。

  • Launch height（抛出点高度）h：发射点比落地点高多少。所以落地时 sy = −h。

求时间的四步

  1. 写竖直方向：−h = uyt + ½ayt²，其中 ay = −9.8。
  2. 整理成 4.9t² − uyt − h = 0。这是一个 quadratic equation（一元二次方程）：有 t² 项、t 项和一个数。
  3. A = 4.9，B = −uy，C = −h，代进 t = (−B ± √(B² − 4AC)) / 2A。
  4. 会得到两个 root（根（方程的解））。取正的那个。负的那个在发射之前，没有意义。然后算射程 R = uxt。
  • 平地的 tflight 和 R 公式在这里不能用。
  • 目标比发射点高时，会有两个正根：一个是上去时经过，一个是下来时经过。
  • 发射点更高：时间更长，射程更远。但 hmax（从发射点量）不变。
  • 从高处发射，最远的角度小于 45°。多出来的那段下落，让球在空中更久。所以多给 ux 一点速度更划算。在动画 3 里把抛出点高度 h 调大试试。

1.2

落地时的速度Final velocity

一句话Final velocity（末速度）就是落地前一刻的速度。要给出大小，也要给出方向。

  • 水平：vx = ux。
  • 竖直：vy = uy + ayt，或者 vy² = uy² + 2aysy。球往下走时 vy 是负的。
  • 然后把两部分合起来：速率用勾股定理，方向用 tan。α 是水平线下方的角度。
  • 平地上：sy = 0，所以 vy = −uy。落地速率 = 发射速率，角度 = 抛射角，只是在水平线下方。

1.3

飞行中的能量Energy and air resistance

一句话没有空气阻力时，动能加势能一直不变。用它可以直接求某个高度的速率，不用时间，也不用角度。

  • 上升时，kinetic energy（动能，K = ½mv²）变成 gravitational potential energy（引力势能（地面附近：重力势能），ΔU = mgΔh）。下降时又变回来。
  • 总量一直不变，这叫 conservation of energy（能量守恒）。像过山车：往上爬变慢，往下冲变快。
  • 斜着抛的球，在最高点 K 最小，但不是 0。球还在以 ux 往前走，所以 Ktop = ½mux²。
  • 动能增加了多少 = 势能减少了多少。两边都有 m，可以约掉。

1.3

空气阻力：模型不准的地方Air resistance: where the model fails

一句话真实的空气会往后拉球。所以真实的球飞得更近、更低，路径也不再对称。

  • Drag（空气阻力，air resistance）是一个额外的力，方向和速度相反。速度越快，阻力越大，而且大得很快。
模型：没有空气阻力

路径对称。平地上 45° 最远。落地速率 = 发射速率。K + U 一直不变。

真实：有空气阻力

射程更短（阻力让水平运动变慢）。最高点更低（上升时阻力和重力一起往下拉）。不对称：下降更陡，用时更长。落地更慢。最远的角度小于 45°。

  • 模型很准：小的、dense（密度大的，个子小但分量重）、慢的物体，飞得不远。阻力几乎改变不了重物体的运动。比如一个小钢球。
  • 模型不准：轻的、大的或很快的物体。比如一根羽毛，或者刚被一杆打出去的高尔夫球。

动画 4 把两个球放在一起飞：一个按模型飞，一个有空气阻力。旁边的能量柱（手机上在下面）同时演示 1.3 前半节的能量守恒。

1.4

预测运动：匀速直线运动和恒定加速度Predicting motion: uniform velocity and constant acceleration

一句话直线运动只有两个模型：匀速直线运动和恒定加速度。抛体同时用两个：水平用匀速直线运动，竖直用恒定加速度，共用同一个 t。

  • Prediction（预测）：还没测量之前，用模型算出来的结果。
Uniform velocity

匀速直线运动（速度恒定）：一样快、同一个方向。合力 = 0（Newton's first law，牛顿第一定律）。s = ut，v = u。位移–时间图是直线，斜率 = 速度。

Constant acceleration

恒定加速度（匀变速）：速度每秒变一样多。合力恒定（Fnet = ma），比如 free fall（自由下落（只受引力））。速度–时间图是直线：斜率 = 加速度，下面的面积 = 位移。

怎么选模型：每个方向分开选

这个方向的合力用哪个模型
没有合力Uniform velocity
合力恒定Constant acceleration
力在变（比如阻力很大）两个都不准

下落的物体绝不能用 s = ut。它的速度一直在变。

两种特别的情况

  • 竖直上抛（ux = 0）：上升时间 = 下降时间。回到手里时，速率和抛出时一样。最高点以下，每个高度都经过两次（两个正的 t）。
  • 从运动的车上抛：放手以后，物体还保留车的速度，这叫 inertia（惯性）。在匀速前进的小车上把球竖直往上抛，球会落回车里。站在地面上看，球走的是 parabola。匀速飞行的飞机放下一个包裹，包裹一直在飞机正下方。
  • 类比：在平稳开着的公交车上往上抛钥匙，钥匙还是落回你手里，不会飞到车后面去。

怎么预测：三样东西

  1. 一个 origin。
  2. 每个物体、每个方向，选一个模型。
  3. 一个时钟 t。“在同一个位置”就给出一个关于 t 的方程，解出 t。
1.5

必做实验Key experiments

水平抛出的球的射程（Range of a ball launched horizontally）

目的
收集 primary data（一手数据（原始数据），自己测的数据），去 validate（验证）R = u√(2h/g)：R 对 u 的图应该是一条过原点的直线，斜率 √(2h/g)。
做法
钢球从斜坡水平的末端离开，所以 uy = 0。Light gate（光电门）测钢球挡住光束的时间：u = 直径 ÷ Δt。Carbon paper（复写纸）记下落点，R 从 plumb line（铅垂线，下面挂重物、直直垂下的线）量起。改变 u（5 个速度，每个做 5 次），h 和球都不变。h 是斜坡末端比地面高多少。
结果
R 对 u 的图（h = 0.900 m）是一条非常接近原点的直线，gradient（斜率）0.423 s（模型：0.429 s）。从斜率算出的 g 比 9.8 m s−2 高约 3 %。
结论
R 和 u proportional（成正比）：u 翻倍，R 也翻倍。数据验证了模型（对 dense、慢的球）。每个 R 都低约 2 %：这是 systematic error（系统误差，每次都偏同一个方向），不是模型错了。
意义
每个速度的下落时间都一样，所以 R 跟着 u 一起变。这说明水平和竖直运动相互独立。动画 1 里的 R–u 图演示的就是这件事。

考试前背这 7 句

  1. 水平和竖直两个运动相互独立，只共用时间 t。
  2. ux = u cos θ，uy = u sin θ。vx 不变。ay = −9.8 m s−2，连最高点也是。
  3. 水平抛出：t = √(2h/g)。下落时间只看高度。
  4. 平地：hmax = uy²/2g，tflight = 2uy/g，R = u² sin 2θ / g（45° 最远）。
  5. 从高处抛出：解 −h = uyt − ½gt²，取正根。
  6. 末速度要有大小和方向。能量只给速率。
  7. 空气阻力：路径更近、更低、更陡。模型适合 dense、慢的物体。

常见错误

错：球在最高点速度是 0，加速度也是 0。
对：最高点只有 vy = 0，还在以 vx 往前走；加速度一直是 g 向下。
错：水平抛出时 uy = u。
对：水平抛出时 uy = 0，ux = u。
错：算 ttop、hmax 时代 u。
对：代 uy = u sin θ。
错：在 hmax = uy²/2g 里代 g = −9.8，或在 t = √(2h/g) 里代 −h。
对：这些式子里 g = 9.8，h 是正数，负号已经在式子里了。
错：角度从竖直量，还用 ux = u cos θ；计算器在 radian mode（弧度制）。
对：从竖直量时 ux = u sin θ；计算器用 degree mode。
错：从高处抛出，也用 R = u² sin 2θ / g，也说 45° 最远。
对：这个公式只用于平地、没有空气阻力。从高处要解二次方程，取正根；最远的角度小于 45°。
错：末速度只写速率，或者用能量求出角度。
对：末速度要写方向（水平线下方 α）。能量只给速率，角度用 vx = ux 来求。
错：竖直方向用 s = ut。
对：下落的物体绝不能用 s = ut；竖直方向有重力，要用恒定加速度的公式。

快问快答点一下看答案

1. 同一高度，A 自由落下，B 同时水平抛出。谁先落地？

同时落地。两个都是 uy = 0，ay = −9.8 m s−2。水平速度不影响竖直运动。

2. 斜抛的球到最高点时，速度是 0 吗？加速度呢？

速度不是 0，等于 vx；加速度是 9.8 m s−2 向下。最高点只有 vy = 0。重力一直在，所以加速度从来不是 0。

3. 球从 h = 0.900 m 的桌边以 2 m s−1 水平抛出。多久落地？射程多少？

t = 0.429 s，R = 0.857 m。t = √(2h/g) = √(2 × 0.900 / 9.8) = 0.429 s。R = ut = 2 × 0.4286 = 0.857 m。

4. 平地上以 20 m s−1、30° 抛出。求竖直分量、飞行时间、最大高度和射程。

uy = 10 m s−1，tflight = 2.04 s，hmax = 5.10 m，R = 35.3 m。uy = 20 sin 30° = 10；tflight = 2 × 10 / 9.8 = 2.04 s；hmax = 10² / (2 × 9.8) = 5.10 m；R = 20² × sin 60° / 9.8 = 35.3 m（也可以 ux × tflight = 17.3 × 2.04）。

5. 接上题：换成 60°，射程变不变？哪个飞得更高？

射程一样，还是 35.3 m；60° 更高。30° 和 60° 是 complementary angles，sin 60° = sin 120°。60° 的 hmax = (20 sin 60°)² / 19.6 = 15.3 m，在空中 3.53 s。

6. 从 4.9 m 高处以 3 m s−1 水平抛出。落地速度多大？什么方向？

约 10.2 m s−1，在水平线下方约 73°。t = √(2 × 4.9 / 9.8) = 1 s；vy = −9.8 × 1 = −9.8 m s−1；v = √(3² + 9.8²) = 10.2 m s−1；tan α = 9.8 / 3，α = 73.0°。用能量也能得到速率：v = √(u² + 2gh) = √(9 + 96.04) = 10.2 m s−1，但能量给不出方向。

7. 有空气阻力时，和模型比，路径有哪些变化？

射程更短，最高点更低，下降更陡、更久，落地更慢。阻力和速度方向相反，让水平运动变慢；上升时还和重力一起往下拉。最远的角度也小于 45°。

8. 匀速飞行的飞机放下一个包裹（没有空气阻力）。包裹落地时在飞机的哪里？

正下方。因为 inertia，包裹放下后还保留飞机的水平速度。水平方向没有力，所以包裹的 vx 一直等于飞机的速度。
