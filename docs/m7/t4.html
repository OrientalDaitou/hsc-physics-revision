Light and Special Relativity

光与狭义相对论 · 零基础讲解

这一章从一个奇怪的事实出发：不管你跑多快，量到的光速都一样。由它推出：动的钟变慢，动的东西变短，有质量的东西永远追不上光，质量能变成能量。记住下面三条规则，整章都只是在用它们。

规则 ①
All inertial frames of reference are equivalent.

Einstein 的 postulate 1（基本假设，也叫公设）：不加速的 inertial frame（惯性参考系）都平等。物理规律都一样，没有实验能分出谁“真的”静止。

物理规律：frame A = frame B
规则 ②
The speed of light in a vacuum is an absolute constant.

Postulate 2：每个人量到的真空光速都是 c，不管光源和观察者跑多快。

c = 3.00 × 108 m s−1
规则 ③
The factor √(1 − v²/c²)

v 越接近 c，这个根号越接近 0：动的钟变慢，动的东西变短，momentum（动量）冲向无穷大。

先会这 4 样Before we start

  1. 匀速运动：s = vt，距离 = 速度 × 时间。muon 那一节要用。
  2. Pythagoras（勾股定理）：直角三角形里，两条直角边的平方加起来，等于斜边的平方。光钟那一节要用。

4.1

从哪里看？参考系和以太Frames of reference and Einstein's postulates

一句话运动总是从某个“视角”量出来的。Einstein 说：不加速的视角没有哪一个是特别的；而且每个人量到的真空光速都一样。

  • Frame of reference（参考系）：一个“视角”，带着自己的尺子和钟。站台是一个 frame，火车是另一个 frame。
  • Inertial frame：不加速的 frame，静止或者匀速直线走。注意：不变的是速度（velocity，包括方向）。
  • Non-inertial frame（非惯性参考系）：在加速、减速或者转弯的 frame。地面通常可以当成 inertial frame。
  • Event（事件）：在一个地点、一个瞬间发生的事，比如一次闪光。
  • Postulate：一个理论一开始就当成对的话。上面的规则 ①、② 就是 Einstein 的两条 postulate。
  • Galilean relativity（伽利略相对性原理）：运动的规律在每个 inertial frame 里都一样，日常的速度可以直接相加。在匀速的火车上扔球，和在地上扔一样。Einstein 的 postulate 1 把它推广到所有物理。

光速是“相对谁”的？

  • Maxwell 的方程算出光只有一个速度：c = 3.00 × 108 m s−1。可是它没说相对谁。
  • 当时大家觉得，光要有一个 medium（介质：让波传过去的东西，像声音靠空气）。于是假设太空里充满一种看不见的东西，叫 luminiferous aether（以太，也叫光以太）。
  • 地球在太空里跑，大约 30 km s−1。如果有 aether，地球上就会吹着“aether 风”（aether wind），光速应该随方向变：顺风快，逆风慢。
  • Michelson 和 Morley（1887）去测这个变化，结果什么变化都没有。这叫 null result（零结果：没找到要找的效果）。
  • 他们用的仪器叫 interferometer（干涉仪）。光从 source（光源）出来，一面 half-silvered mirror（半镀银镜）把它分成互相垂直的两束。每一束沿一条 arm（臂）走到 mirror（镜子），再回来。两束光合在一起进 telescope（望远镜），形成 fringes（条纹：一条亮、一条暗）。光速一变，fringes 就会移动。实验细节在 4.5，先看动画 1。

4.1

Einstein 的两条 postulateEinstein's two postulates (1905)

一句话整个 special relativity（狭义相对论）只站在两条 postulate 上。它们的英文原句要背下来，一个字都不能错。

Special relativity：讲 inertial frame 里的人看到的空间和时间是什么样的理论。

  1. All inertial frames of reference are equivalent.
    物理规律（包括光的规律）在每个 inertial frame 里都一样。没有实验能分出哪个 inertial frame “真的”静止。
  2. The speed of light in a vacuum is an absolute constant.
    每个 inertial observer（观察者）量到的都是 c = 3.00 × 108 m s−1，不管光源或者观察者跑多快。
  • 按 postulate 1，Maxwell 的方程在每个 inertial frame 里都成立，所以每个 frame 都算出同一个 c。
  • 光的速度不能相加：车在开，车灯的光还是 c，不是 c + v。
  • 两个相对运动的人量同一束光，都得到 c。只有一个办法让它成立：他们量的距离、时间（或者两样都）不一样。4.2 就讲这个。
  • c 只在真空里不变。光在玻璃和水里会变慢。

4.2

“同时”也是相对的Time dilation and length contraction · Thought experiment 1: lightning and a fast train

一句话每个人量到的光速都一样，所以互相运动的人，对时间和长度的看法一定不一样。第一个例子：一个人看是同时发生的两件事，另一个人看不是同时。

  • Thought experiment（思想实验）：在脑子里做的实验，一步一步用逻辑推。它能想象接近 c 的速度。这种速度，1905 年没人能拿来做实验。
  • 它不是证据。它只告诉我们理论预测什么。要靠真实的实验来检验。

闪电和快车（讲义图 4.1）

  1. 火车往右开，速度 v。Peter 坐在火车正中间。Olivia 站在站台上，正好在 A 和 B 的中间。
  2. 站台上看：闪电同时打在 A 和 B，正好是火车的两头（rear 车尾，front 车头）。
  3. Olivia：两个闪光（flash）同时到她。所以对她来说，两次闪电是 simultaneous（同时的）。
  4. Peter：火车带着他迎向 front 的闪光，所以 front 的闪光先到他。
  5. Peter 想：我在车的正中间，我是静止的。两个闪光都以 c 走一样远的路。front 的先到，所以对我来说，front 那一下真的先打。他的 frame 和 Olivia 的一样有效（postulate 1）。
站台 frame（Olivia）

两次闪电同时打下。Peter 迎着 front 的光走，所以先看到 front 的光。

火车 frame（Peter）

Peter 不动。两个光都是 c、走一样远，front 的先到，所以 front 先打。

这就是 relativity of simultaneity（同时的相对性）：在不同地点发生的两个 event，在一个 frame 里同时，在另一个沿着它们的连线运动的 frame 里，就不同时。两个人都对。

4.2

光钟：动的钟走得慢Thought experiment 2: the light clock

一句话动的钟走得慢。在别人看来，钟里的光走的是斜线，路更长；可光速还是 c，所以每一下都要更久。

  • Light clock（光钟）：两面镜子，一束光在中间上下来回。光走一个来回，钟就“滴答”一下，叫一个 tick。
  • (a) 钟不动：光一个来回走 2d，所以一个 tick 是 t0 = 2d/c。
  • (b) 钟以速度 v 往右走（你站着不动看它）：光要走斜线，才追得上已经往前移的镜子。斜线更长。
  • 但光速还是 c（postulate 2）。路长了，速度没变，时间就长了：每个 tick 都更久。这就是 time dilation（时间膨胀，也叫时间延缓）。

用 Pythagoras 算出来（讲义图 4.2）

  1. 看 (b) 里的直角三角形。斜边：光走半个 tick 的路，ct/2。竖边：两面镜子的距离 d。横边：钟走半个 tick 的路，vt/2。
  2. Pythagoras：(ct/2)² = d² + (vt/2)²。
  3. 整理一下：t = 2d/√(c² − v²) = (2d/c)/√(1 − v²/c²)。
  4. 把 t0 = 2d/c 放进去：t = t0/√(1 − v²/c²)。
  • 根号里的数比 1 小，所以 t 永远比 t0 大。v = 0 时两个一样。
  • 倍数 1/√(1 − v²/c²) 有个名字：Lorentz factor（洛伦兹因子），写成 γ。例如 v = 0.6c：√(1 − 0.6²) = 0.8，γ = 1.25，动的钟一个 tick 是 1.25 倍长。

也可以自己推导：钟不动时，光一个来回走 2d。时间 = 距离 ÷ 速度 = 2d/c。
例子：d = 1.5 m：t0 = 2 × 1.5 / (3.00 × 108) = 1.0 × 10−8 s = 10 ns。
陷阱：这是钟自己 frame 里的 tick。看它在动的人，量到的 tick 更长。

4.2

固有时、固有长度和 muonProper time and proper length · Muons: both effects in action

一句话动的东西沿运动方向变短。Muon 把“钟变慢”和“长度变短”都用上了：换一个 frame 看，结果完全一样。

谁量的才算 proper？

  • Proper time（固有时，也叫原时）t0：两个 event 之间的时间，用一个两个 event 都在场的钟量。不管在哪个 frame：muon 自己的钟量它的一生，飞船上的钟量一次旅行。别人量到的 t 都更长。
  • Proper length（固有长度，也叫原长）l0：在东西静止的那个 frame 里量的长度。
  • Length contraction（长度收缩，也叫尺缩效应）：动的东西被量得更短。只沿运动方向变短，横着不变。
  • 地球到一颗星的距离：l0 在 Earth–star frame 里量（地球和星星在这个 frame 里都不动）。
  • 两种效果都是相互的：A 看 B 的钟慢，B 看 A 的钟也慢。你自己的钟和尺子，在你看来永远正常。
  • 日常速度下，效果非常小（v = 0.1c 时，t 也只比 t0 长约 0.5 %）。接近 c 才变得很大。

Muon：两种效果一起看（讲义图 4.3）

  • Cosmic rays（宇宙射线：从太空飞来的快速质子）在 10–15 km 高的空中撞出 muon（μ子，也叫缪子）。muon 像一个很重的电子。
  • Muon 是 unstable（不稳定的）：过一会儿就 decay（衰变）成别的粒子。静止时它的 mean lifetime（平均寿命）是 2.2 μs。
  • 没有 relativity 的话：用 s = vt，就算差不多以光速飞，也只能走大约 660 m。可是很多 muon 到了地面。
(a) Earth frame（地面看）

muon 的钟变慢，它活得够久，能飞完整段空气 l0。用的是：变长的时间 t + proper length。

(b) muon frame（muon 自己看）

muon 不动，地面冲上来。它只活 t0，但空气层被压短成 l，够用了。用的是：proper time + 变短的长度。

  • 两个 frame 的结论一样：muon 到了地面。永远不要在同一个 frame 里同时用“变长的时间”和“变短的长度”。

证据

  • Frisch and Smith（1963）：数速度约 0.995c 的 muon。在 1.9 km 高的山上，每小时 563 个；在海平面，每小时 408 个。如果没有 time dilation，只会剩大约 30 个。
  • 用这些计数算出的变慢倍数约是 9。按 0.995c 算应该是 10；差一点，是因为 muon 在空气里会减速。
  • CERN（1977）：把 muon 存在一个环里，以 0.999418c 转圈。它们活得比静止时长 29.3 倍，正是 time dilation 的预测。

4.3

越推越难：速度上限是 cRelativistic momentum and the speed limit

一句话接近 c 时，momentum 涨得比 m0v 快得多，一直冲向无穷大。所以有质量的东西永远到不了光速。

  • 接近 c 时，p = mv 不对了：用它算，momentum 会在一个 inertial frame 里守恒、在另一个里不守恒。这违反 postulate 1。
  • 要用 relativistic momentum（相对论动量）pv。它用的是 rest mass（静止质量）m0：东西静止时量到的质量。
  • v → c（越来越接近 c）时，根号 → 0，所以 pv → ∞（讲义图 4.4）。
  • 有限的力推有限的时间，只能给有限的 Δp = FnetΔt。要把 momentum 推到无穷大，做不到。所以 v 永远到不了 c。
  • 换句话说：你一直用同样的力推。momentum 每秒都涨一样多，可是速度涨得越来越少，永远差一点点到 c。
  • 速度低于约 0.1c 时，pv ≈ m0v，两条线几乎重合。
  • Photon（光子）没有 rest mass，它永远以 c 走。

证据和应用

  • Bertozzi（1964）：把 electron（电子）加到最多 15 MeV 的能量。它们越来越接近 c，但从来没超过。
  • LHC（Large Hadron Collider，大型强子对撞机，CERN 最大的加速器）给 proton（质子）的能量是它 rest energy（静能：因为有质量而有的能量，见 4.4）的 7000 倍。可它们还是比 c 慢。
  • 磁铁能让运动的电荷走圆：r = p/(qB)（从 qvB = mv²/r 来）。不在 sheet 上，要背。
  • Synchrotron（同步加速器：一种环形的加速器）：环的半径 r 固定，所以磁场 B 要跟着 pv 一起变大，不是跟着 m0v。它每天都在检验 relativity。
  • HSC 的公式里 m0 不变：变大的是 momentum，不是质量。

4.4

质量就是能量Mass–energy equivalence: E = mc²

一句话质量是浓缩得非常厉害的能量。放出能量时，会丢掉一点质量：放出的能量 = 丢掉的质量 × c²。

  • 任何质量 m 都有 rest energy（也叫静止能量）E = mc²。
  • c² = 9.00 × 1016 m² s−2，大得吓人。所以一点点质量 = 非常多的能量。1 g 质量，大约等于一个大电站一天发的电。
  • 每个放出能量的过程都会丢质量。一个密封的盒子，只有能量跑出去时才变轻。
  • 反过来也行：碰撞的能量可以变成新的粒子。
  • Mass defect（质量亏损）Δm = 之前的质量 − 之后的质量，就是消失了的那部分质量。

两条路，不能混

质量用 u

u 是 atomic mass unit（原子质量单位）。乘 931.5，得到 MeV。

质量用 kg

用 E = mc²，得到 J。1 eV = 1.602 × 10−19 J。

  • Positron（e+）：electron 的 antiparticle。质量一样，带正电。

4.5

三个关键实验Key experiments

Michelson and Morley（1887）：找 aether

目的
测出地球在 aether 里的运动。
做法
用一台 interferometer（干涉仪，讲义图 4.6）。光从 source（光源）出来，被一面 half-silvered mirror（半镀银镜：一半光穿过去，一半光反射）分成互相垂直的两束。每一束沿一条臂走到镜子，再回来。两束合在一起，在 telescope（望远镜）里形成干涉 fringes（条纹：一条亮、一条暗）。整台仪器浮在 mercury（水银）上，慢慢转，一天里不同时间、一年里不同时候都测。光速一变，fringes 就会移动。看 动画 1（在 4.1）。
结果
预测：移动约 0.4 条 fringe。实际看到：不到 0.02 条（null result）。
结论
没有 aether 风：在运动的地球上，光在每个方向的速度都一样。
意义
没有证据说明有 aether。这个结果和两条 postulate 都对得上。

Hafele–Keating 原子钟（1971）

目的
用非常准的原子钟坐飞机绕地球飞，检验 time dilation。
做法
四个 caesium（铯）atomic clock（原子钟）坐飞机绕地球一圈：先往东飞，再往西飞，然后和地面上的钟比。从地球中心看，往东飞的钟最快（地球本身也往东转），所以它走得最慢。
结果
往东的钟少了 59 ns（预测 40 ns）；往西的钟多了 273 ns（预测 275 ns）。预测里还算进了重力的影响（general relativity，广义相对论，不在 HSC 范围内）。
结论
量到的和预测的，在误差范围内对得上：动的钟走得慢，飞机这么慢的速度也看得出来。
意义
用真实的钟、在日常速度下，给了 time dilation 直接的证据。GPS 卫星也要做类似的修正：速度和重力加在一起，每天约 38 μs。

来自宇宙的证据：慢动作的超新星

目的
检验很远的星系里发生的事，是不是也被量得变慢。
做法
每一颗 Type Ia supernova（Ia型超新星：一种爆炸的恒星）变暗的过程几乎都一样。测了几百颗变暗用多久，再量每一颗的 redshift（红移）z：光被拉长了多少。
结果
越远的变暗越慢，慢 1 + z 倍（z = 1 时，用两倍的时间）。
结论
Cosmological time dilation（宇宙学时间膨胀），主要来自宇宙的膨胀（general relativity）。
意义
宇宙学研究给出的 time dilation 证据：就算放到整个宇宙，时间也不是绝对的。

例子：z = 1：1 + z = 2。波长被拉长成 2 倍，变暗的过程也慢成 2 倍。

考试前背这 6 句

  1. Postulate 1：All inertial frames of reference are equivalent. Postulate 2：The speed of light in a vacuum is an absolute constant.
  2. “同时”是相对的。动的钟走得慢（t > t0）；动的东西沿运动方向变短（l < l0）。muon 两样都能看到。
  3. Proper time t0：两个 event 都在场的钟量的。Proper length l0：在东西静止的 frame 里量的。
  4. v → c 时，pv → ∞，所以有质量的东西到不了 c。
  5. ΔE = Δm c²：Sun 丢约 0.7 %，annihilation 丢全部，烧燃料丢得极少。
  6. 证据：Michelson–Morley、muon、原子钟、加速器、超新星。

常见错误

错：车灯的光速度是 c + v（Galilean 相加）。
对：光永远是 c（postulate 2）。Galilean 相加只用在日常速度上。
错：光在哪里都是 c。
对：只有在真空里是 c。在玻璃和水里会变慢。
错：Thought experiment 证明了 relativity。
对：thought experiment 只说明理论预测什么，不是证据。真实实验（muon、原子钟……）也只是支持理论，不是证明它。
错：v = 0.9c 时算 √(1 − 0.9) = 0.32。
对：先把 v/c 平方：√(1 − 0.9²) = 0.44。
错：算出 t < t0 或 l > l0。
对：永远 t > t0，l < l0。算反了，就是 proper 的那个放错了。
错：在一个 frame 里，同时用变长的时间和变短的长度。
对：Earth frame：变长的时间 t + l0。muon frame：t0 + 变短的 l。一个 frame 只用一种。
错：动的东西每个方向都变短。
对：只沿运动方向变短，横着不变。
错：接近 c 时质量变大；photon 也用 pv 公式。
对：HSC 公式里 m0 不变，变大的是 momentum。photon 没有 rest mass，不能用这个公式。
错：pv 公式分子上的 v 直接放 0.6。
对：v 用 m s−1：0.6 × 3.00 × 108。
错：质量用 u 时乘 c²；或者用整个物体的质量算放出的能量。
对：用 u 就乘 931.5（得 MeV）；用 kg 才用 E = mc²（得 J）。只用丢掉的质量 Δm，c 要平方。

检查

快问快答点一下看答案

1. 写出 Einstein 的两条 postulate（英文原句）。

1. All inertial frames of reference are equivalent. 2. The speed of light in a vacuum is an absolute constant.第一条：物理规律在每个 inertial frame 里都一样。第二条：每个人量到的真空光速都是 c。

2. 火车上的 Peter 说 front 的闪电先打，站台上的 Olivia 说两个同时打。谁对？

两个都对。每个 inertial frame 都一样有效（postulate 1）。不同地点的两个 event，在一个 frame 里同时，在另一个沿着它们的连线运动的 frame 里就不同时：这就是 relativity of simultaneity。

3. 飞船以 0.6c 飞过地球。飞船上的钟过了 8.0 s，地球上的人量到过了多久？飞船自己量长 100 m，地球上的人量它多长？

10 s；80 m。√(1 − 0.6²) = √0.64 = 0.8。t = 8.0 / 0.8 = 10 s（t > t0）。l = 100 × 0.8 = 80 m（l < l0）。

4. v = 0.9c。一个学生算 √(1 − 0.9) = 0.32。错在哪？动的钟一个 tick 是 t0 的几倍？

要先把 0.9 平方；约 2.3 倍。√(1 − 0.9²) = √0.19 ≈ 0.436（约 0.44）。t = t0 / 0.436 ≈ 2.29 t0，约 2.3 倍。

5. Muon 静止时平均活 2.2 μs。以 0.995c 飞时（倍数是 10），地面上看，它平均能飞多远？

约 6.6 km。地面上看，muon 的钟慢 10 倍，它平均活 2.2 × 10 = 22 μs。s = vt = 0.995 × 3.00 × 108 × 22 × 10−6 ≈ 6.6 × 103 m。没有 relativity 只有约 660 m。

6. 在 muon 自己的 frame 里，它只活 2.2 μs。为什么它也能到地面？

因为空气层被压短了。在 muon frame 里，muon 不动，地面以 0.995c 冲上来。空气层的长度 l = l0√(1 − v²/c²)，只有原来的约 1/10。这里用 proper time + 变短的长度，不能再用变长的时间。

7. 一个不变的力一直推一个粒子。为什么它永远到不了 c？

到 c 要无穷大的 momentum。v → c 时 pv → ∞。有限的力推有限的时间，只给有限的 Δp = FnetΔt。所以 v 只能越来越接近 c。

8. Sun 每秒少 4 million tonnes（4 × 109 kg）质量。它的功率是多少？

约 3.6 × 1026 W。P = (Δm/Δt) × c² = 4 × 109 × 9.00 × 1016 = 3.6 × 1026 W。
