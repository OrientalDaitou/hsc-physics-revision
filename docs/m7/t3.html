光的粒子性：黑体辐射和光电效应 · 零基础讲解

热身

先会这 4 样Before we start

  1. EM spectrum（电磁波谱）的顺序：radio → microwaves → infrared（红外线）→ visible（可见光，红到紫）→ UV（ultraviolet，紫外线）→ X-rays → gamma。越往后，f 越高，λ 越短。真空里 c = fλ，c = 3.00 × 108 m s−1（第 1 章）。
  2. 温度要换成 kelvin（开尔文，K）：T(K) = T(°C) + 273。例如 27 °C = 300 K。
  3. 电压做功 W = qV。电子电荷的大小 q = 1.602 × 10−19 C。一个电子走过 1 V，得到的能量是 1 electron volt（电子伏特，eV）：1 eV = 1.602 × 10−19 J。动能 K = ½mv²。
  4. 第 2 章的结论：干涉和衍射说明光是波。在 wave model（波动模型）里，光越亮 = amplitude（振幅）越大 = 能量越多。
3.1

热的东西怎样发光Black body radiation: the black body curve and Wien's law

一句话黑体发出的光只看它的温度。1900 年 Planck 解释了曲线为什么是这个形状：能量一份一份地放出去，一份是 E = hf。

  • 所有物体都因为自己的温度，向外发出 EM 波，叫 thermal radiation（热辐射）。原因：物体里的电荷在振动，振动的电荷发出 EM 波。不太热的东西，发的大多是看不见的 infrared。
  • Black body：一个理想的物体。照到它上面的辐射，它全部吸收。它也是最好的发射体（perfect emitter）。
  • 一个空心盒子开一个很小的孔，就差不多是 black body：光从小孔进去，就出不来了。恒星也差不多是 black body。
  • 例子：lava（熔岩，约 1000 K 到 1500 K）的峰在 infrared，发暗红光。Sun（太阳，5800 K）看起来是白的。更热的恒星看起来蓝白。
  • Wien（1893）：λmax 和 T 成反比（inversely proportional）。T 翻倍，λmax 减半。
  • Intensity（光强，也叫强度）：每秒落在每平方米上的辐射能量。黑体曲线的纵轴就是它，横轴是波长。

黑体曲线的四个特点

  1. 只有一个峰，在 peak wavelength（峰值波长）λmax：曲线最高的那个波长。短波一侧爬得很陡，长波一侧拖着一条长尾巴。
  2. 越热的物体，在每一个波长上都更高。两条曲线永远不相交。
  3. 越热，峰越往短波走。
  4. 曲线只看温度，不看是什么材料。

3.1

紫外灾难和 Planck 的能量台阶The ultraviolet catastrophe · Planck's idea: energy comes in packets

一句话老的物理预测：波长越短，光越多，一直到无穷大。真实曲线却掉到 0。Planck 说：能量只能一份一份地给，短波的那一份太大，很少给得出来。

老的物理错在哪

  • Classical physics（经典物理学，1900 年以前的物理）：光是波，能量可以是任何大小。
  • 它对黑体曲线的预测叫 Rayleigh–Jeans law（瑞利–金斯公式）。在长波一侧，它和测量曲线对得上；波长越长，两条线靠得越近。
  • 在短波一侧，它一直往上涨，没有尽头。加起来，总能量会是无穷大。真实的曲线却掉到 0。
  • 这个错误的预测叫 ultraviolet catastrophe（紫外灾难）：1900 年以前的物理预测，在短波（UV 那边）intensity 无穷大。
  • 讲义图 3.2 画的是 T = 5000 K：经典预测冲向无穷大，测量曲线（Planck 的公式对得上它）有一个峰，再落下来。

为什么错：热盒子里，波长越短，能放下的驻波样式（standing-wave patterns）越多。经典物理给每个样式分一样多的能量。样式越来越多，总能量就是无穷大。就像每个小朋友都要分一样多的糖，小朋友无穷多，糖就要无穷多。

Planck 的想法：能量一份一份地来

  • Planck（1900）：墙里振动的电荷叫 oscillators（振子）。它们的能量是 quantised（量子化的）：像台阶，只能是 0, hf, 2hf, 3hf, …，不能停在两级中间。
  • 所以它们放出或吸收能量，只能一份一份地来，一份 hf。一份叫一个 quantum（复数 quanta）。h 是 Planck's constant（普朗克常量），6.626 × 10−34 J s。
  • 经典物理像一个斜坡：能量可以停在任何高度。Planck 像楼梯：只能站在某一级上。
低 f（长波）

每级台阶 hf 很小，小到像斜坡。所以在这里，Planck 和经典物理的结果一样。

高 f（短波）

一级台阶 hf 比 oscillator 平时有的热能还大。它很难爬上第一级，很少放出 quanta，所以曲线掉到 0。

  • 类比：一台游戏机一次要投 10 个币，你平时手里只有两三个币，几乎玩不了。短波的一份 hf 就是这“10 个币”。
  • Planck 的公式在每个波长都和测量曲线对得上。他自己觉得 quanta 只是一个数学技巧（maths trick）。但它开启了光的 quantum model（量子模型）。

3.2

光把电子打出来The photoelectric effect: evidence against the wave model · Stopping voltage

一句话光能把电子从金属里打出来。实验发现，wave model 的三个预测都是错的。

  • Photoelectric effect（光电效应）：光照在金属表面上，电子被放出来。
  • Hertz 最早看到它（1887）：UV 帮火花跳过 spark gap（火花隙：两个金属球之间的一小段空气）。Lenard 用真空管测量了它（1902）。

装置（讲义图 3.3）

  • 光照在金属 cathode（阴极）上，打出电子，叫 photoelectrons（光电子）。它们飞过真空，到 anode（阳极）。
  • Microammeter（微安表：测很小电流的表）测 photocurrent（光电流）。电流大 = 每秒的电子多，不是电子快。
  • 管子里是真空：电子不会撞到空气分子。窗子是 quartz（石英）做的，让 UV 进来（玻璃会吸收 UV）。
  • 电路里有一个能反过来接的电源和一个电压表（reversible supply and voltmeter）。讲义图 3.3 里 anode 是负的，这是用来找 V0 的接法。
  • Electroscope（验电器）演示：electroscope 里有一片很薄的金箔，带电时金箔张开。把一块带负电的锌板放在上面。用 UV 照，金箔落下：电子离开了锌板。用很亮的可见光照，金箔不动。

Stopping voltage（遏止电压）

  • 让 anode 变成负的。它把电子往回推。
  • 电子出来时速度有快有慢。最快的那些有 maximum kinetic energy（最大初动能）Kmax。
  • 反向电压慢慢加大。到 V0 时，连最快的电子也刚好停在 anode 前面，所以 I = 0。V0 叫 stopping voltage：让每个 photoelectron 都停下来、电流为 0 的最小反向电压。
  • 类比：往坡上滚球。坡（反向电压）越高，球要越快才翻得过去。V0 就是连最快的球也刚好翻不过去的那个高度。
  • V0 是电压（V）；Kmax 是能量（J 或 eV）。用 eV 时，Kmax 的数字和 V0 的伏特数一样。例如 V0 = 2.04 V，Kmax = 2.04 eV。
  • 最快电子的速度：把 Kmax（用 J）代进 K = ½mv²（在 sheet 上），m = 电子的质量。

3.2

Wave model 的预测，错了三条What the wave model predicted

一句话按 wave model，光的能量看亮度，不看频率，而且慢慢地、均匀地铺在整个金属表面上。实验一看，四条预测错了三条。

在 wave model 里，光的能量看亮度（amplitude），不看频率。能量平平地铺开，洒在整个表面上（表 3.1）。像毛毛雨：均匀地落在整块地上，每一处慢慢变湿。

Wave model 预测实验看到对吗
光越亮，每秒电子越多（电流越大）。光越亮，电流越大（在 f ≥ f0 时）。对
只要够亮，任何频率都行。有 threshold frequency（截止频率）f0：低于它，再亮也没有电子。错
光很暗时，要等一会儿，电子先攒够能量。没有延迟：电子马上出来（不到 10−9 s）。错
光越亮，电子越快（V0 越大）。V0 和亮度无关。它随 f 直线上升。错

Threshold frequency：能从一种金属里打出电子的最低频率。

Wave model：能量铺开

能量看亮度，均匀地洒在整个表面。每个电子只分到一点点，要慢慢攒。像毛毛雨。

实验：能量一包一包

能量集中在一包一包里，每包 hf。一包打中一个电子，马上给完。像冰雹，一颗打一个地方。

结论：光的能量不可能像波一样铺开来。它一定是一包一包、集中地来，每包 hf。

3.3

Einstein：光就是一个个 photonEinstein's photon model

一句话1905 年 Einstein 说：光本身就是一串 photon，每个的能量是 hf。一个 photon 把全部能量给一个电子，用能量守恒就得到 Kmax = hf − ϕ。

  • Photon：一包（一个 quantum）光，能量 E = hf。
  • 同一种颜色，更亮 = 每秒的 photon 更多。每个 photon 的能量还是 hf，不变。
  • 一个 photon 只和一个电子作用，一次就把全部能量给它。两个 photon 的能量永远不会加起来。像一台只收一枚硬币的机器：要 5 元，你投 1 元的硬币，投一百枚也没用。
  • 每种金属有自己的 work function（逸出功）ϕ：从金属表面拿出一个电子，最少要的能量。例如 caesium（铯）2.1 eV，zinc（锌）4.3 eV。

什么时候用：光照在金属上，而且 hf ≥ ϕ。如果 hf − ϕ 是负的，就没有电子出来。
怎么来的：一个 photon 和 least-bound electron（束缚最弱的电子：最容易拿出来的那个）之间的能量守恒：进来的能量 = 逃出来要的能量 + 剩下的。所以 hf = ϕ + Kmax，Kmax = hf − ϕ。更深的电子要的能量比 ϕ 多，所以出来更慢。
陷阱：每一项用同一个单位：全用 J，或全用 eV。ϕ 是小写的 phi；sheet 上大写的 Φ 是磁通量。

Photon model（光子模型）解释了表 3.1 的每一条

  • 电流更大：每秒 photon 更多，每秒放出的电子就更多。
  • Threshold：一个 photon 至少要给 ϕ，所以要 hf ≥ ϕ。
  • 没有延迟：每个 photon 一次就把全部能量给完。
  • Kmax 只看 f（和金属），不看亮度：亮度改变的是 photon 的个数，不是 hf。

刚好打得出电子：threshold

  • 在 threshold f0，最快的电子也什么都不剩。把 Kmax = 0 放进 Kmax = hf − ϕ，就得到 ϕ = hf0。
  • Threshold wavelength（截止波长）λ0：能打出电子的最长波长。只有 f ≥ f0（λ ≤ λ0）才有电子，光再亮也没用。

Planck、Einstein 和光的新模型

Planck（1900）

量子化的是墙里的 oscillators。他当它是数学技巧。它解释了黑体曲线。

Einstein（1905）

量子化的是光本身：photon 是真的。它解释了光电效应。

  • 两个人用的都是 E = hf。
  • 光仍然有干涉和衍射。但它发出来和被吸收的时候，都是一个一个的 photon。这叫 wave–particle duality（波粒二象性）：光在有些实验里像波，在另一些实验里像粒子。
  • 注意：photon 不是 Newton 说的 corpuscles（微粒）。

I–V 图（讲义图 3.5，理想化）

横轴是管子的电压 V，纵轴是 photocurrent I。右边 anode 正，左边 anode 负（把电子往回推）。动画 3 的右图画的就是它。

  • Anode 正：所有电子都被收走。平的那一段叫 saturation current（饱和电流）：最大的 photocurrent，每个放出来的电子都到了 anode。它的高度由每秒的 photon 数决定。
  • Anode 负：电子被往回推，电流变小。到 −V0 时，电流 = 0。
  • 图里 beam A（光束 A）比 beam B 每秒的 photon 多（平的部分更高），f 也更高（V0 更大）。
  • 同一个 f，光更亮：只有平的部分升高。
  • ϕ 更大，光不变：V0 更小。
3.4

两个关键实验Key experiments

测黑体辐射（1899–1900）

目的
测几个温度下的黑体曲线（Lummer 和 Pringsheim）。
做法
热炉子上开一个小孔，辐射从小孔出来（这就是 black body）。用 thermocouple（热电偶，一种温度计）测炉子的温度。辐射穿过一条 slit（狭缝）和一个 prism（棱镜）：长波弯得少，短波弯得多（讲义图 3.6）。Bolometer（测辐射热计：被辐射加热的探测器）沿着光谱一点点移动。换几个温度，再做一遍。
结果
曲线和图 3.1 一样。每个温度都有 λmaxT ≈ 2.9 × 10−3 m K。
结论
Wien's law。经典理论只对得上长波一侧。
意义
Planck 的公式对得上整条曲线。这让他想到了 quanta（1900）。

光电效应：测 h 和 ϕ

目的
看 V0 怎样随频率和亮度变化（Lenard 1902，Millikan 1914–1916，或学校的 photocell（光电管））。
做法
用图 3.3 的电路，把反向电压慢慢加大，直到电流刚好为 0（这就是 V0）。换几个频率和亮度，再做一遍。
结果
V0 随 f 直线上升。f0 以下没有电流。亮度只改变电流，不改变 V0。
结论
qV0 = hf − ϕ，所以 h = q × gradient；两个截距给出 f0 和 ϕ。这支持 photon model。
意义
Millikan（1914–1916）本来想证明 Einstein 错了。结果他证实了这个规律，测出的 h 和今天的值只差约 1 %。

考试前背这 6 句

  1. 越热的黑体，在每个波长都更高，峰在更短的波长：λmax = b/T，T 用 kelvin。
  2. 经典物理预测了 ultraviolet catastrophe。Planck：能量一份一份地来，E = hf；高 f 的一份太大，很少放出来。
  3. Planck 量子化的是 oscillators；Einstein 量子化的是光本身（photon）。
  4. Wave model 错了三条：有 threshold frequency，没有延迟，Kmax 和亮度无关。
  5. 一个 photon → 一个电子：Kmax = hf − ϕ = qV0。光更亮，电子更多，不是更快。

常见错误

错：λmax = b/T 里直接用 °C。
对：T 用 kelvin，°C 先加 273。
错：λmax = b/T 算出来的数是 nm。
对：算出来是 m，再换成 nm（1 nm = 10−9 m）。
错：E = hf 算出来就是 eV。
对：算出来是 J。J → eV 要除以 1.602 × 10−19。
错：Kmax = hf − ϕ 里，hf 用 J，ϕ 用 eV。
对：全部用 J，或者全部用 eV。
错：ϕ 就是 sheet 上的 Φ。
对：小写 ϕ 是 work function；大写 Φ 是磁通量。同样，λmax = b/T 里的 T 是温度，不是周期。
错：光更亮，电子更快，V0 更大。
对：光更亮 = photon 更多 = 电子更多（电流更大）。Kmax 和 V0 只看 f 和金属。
错：把 eV 直接代进 K = ½mv²，或者用带负号的 qe。
对：Kmax 先换成 J；q 用大小 1.602 × 10−19 C。
错：Kmax–f 图的纵轴截距就是 ϕ。
对：截距是 −ϕ。要外推到 f = 0，再改符号。
错：Planck 发现了 photon。
对：Planck 量子化的是 oscillators，他当它是数学技巧。Einstein 才说光本身就是 photon。

检查

快问快答点一下看答案

1. 一块金属加热到 727 °C。它的 λmax 是多少？峰在哪一段？

2.90 × 10−6 m（约 2898 nm），在 infrared。先换成 kelvin：727 + 273 = 1000 K。λmax = 2.898 × 10−3 / 1000 = 2.898 × 10−6 m。和 lava 一样，峰在 infrared，只发一点暗红光。

2. 经典物理为什么预测出 ultraviolet catastrophe？Planck 怎样解决？

经典物理给每个驻波样式一样多的能量；Planck 让能量一份一份地给。波长越短，样式越多，总能量就无穷大。Planck：oscillator 一次只能放出 hf。短波的 hf 比平时的热能大，很少放得出来，所以曲线掉到 0。

3. f = 10 × 1014 Hz 的光照在 caesium（ϕ = 2.1 eV）上。一个 photon 的能量是多少 eV？Kmax 和 V0 呢？

hf ≈ 4.14 eV；Kmax ≈ 2.04 eV；V0 ≈ 2.04 V。E = 6.626 × 10−34 × 1.0 × 1015 = 6.626 × 10−19 J，除以 1.602 × 10−19 = 4.136 eV。Kmax = 4.136 − 2.1 = 2.04 eV。用 eV 时，V0 的数字一样：2.04 V。

4. 很亮的可见光照锌板，金箔不动；用 UV 一照，金箔就落下。为什么？

看的是每个 photon 的能量，不是亮度。可见光的 f 低，每个 photon 的 hf 比 zinc 的 ϕ = 4.3 eV 小（例如 500 nm 的 photon 只有 2.48 eV）。一个 photon 只给一个电子，两个 photon 不能加起来，所以再亮也打不出电子。UV 的 f 高，hf 够大，一个 photon 就能打出一个电子，马上出来。

5. 同一个 f，光的亮度变成 2 倍。saturation current、Kmax、V0 各怎么变？

saturation current × 2；Kmax 和 V0 不变。更亮 = 每秒 photon 多一倍 = 每秒电子多一倍。每个 photon 还是 hf，所以最快电子的能量不变。

6. zinc 的 ϕ = 4.3 eV。它的 threshold wavelength 是多少？

约 289 nm（UV）。ϕ = 4.3 × 1.602 × 10−19 = 6.89 × 10−19 J。λ0 = hc/ϕ = 6.626 × 10−34 × 3.00 × 108 / (6.89 × 10−19) ≈ 2.89 × 10−7 m = 289 nm。波长比它长的光，打不出电子。

7. 一个 1 W 的光源，发出 f = 5 × 1014 Hz 的光。每秒发出多少个 photon？

约 3.0 × 1018 个。一个 photon：hf = 6.626 × 10−34 × 5 × 1014 = 3.313 × 10−19 J。N/t = P/hf = 1 / (3.313 × 10−19) ≈ 3.0 × 1018 个每秒。

8. Kmax–f 图上，caesium 和 zinc 的线为什么平行？和纵轴交在哪？

斜率都是 h；分别交在 −2.10 eV 和 −4.30 eV。Kmax = hf − ϕ，斜率 h 和金属无关。纵轴截距 = −ϕ，要把虚线外推到 f = 0 才读得到。
